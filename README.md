**1. 球面转动修正 Newton（要写代码）**
- 问题：球面上图案会整体极慢地转动，网格对转动的约束很弱。Newton 一步转不到网格偏好的方向，所以残差停在 9.4e-6（斑点）和 1.9e-4（条纹）。
- 做法：
    1. 构造 3 个转动生成元 T_i U = (e_i × x)·∇_Γ U：逐面 P1 梯度平均到顶点，作用于 u、v。
    2. 求「相对平衡态」：R(U) + Σ c_i M T_i U = 0，加相位条件 ⟨M T_i U0, U − U0⟩ = 0。这是带 3 列稠密边的稀疏 LU。
    3. 报告完整残差和扣除刚体转动后的残差（目标 ≤ 1e-10），并在排除 3 个旋转模后做线性稳定性分析。
    4. 让 `scripts/ai_generation.py` 的球面流程改用它，重跑 `python scripts/ai_generation.py generate --generate-surfaces sphere6`，再更新报告里球面两行。

## 方法要点

**方程与量纲。** ∂u/∂t = Du ΔΓu − uv² + F(1−u)，∂v/∂t = Dv ΔΓv + uv² − (F+k)v。长度以单位球半径为单位，时间以反应时间为单位：[Du] = [Dv] = L²/T，[F] = [k] = 1/T，u、v 无量纲，每一项都是 1/T。特征长度 ℓ = √(Du/F) ≈ 0.10（斑点）/ 0.072（条纹）；单位球半径约 10ℓ，青蛙等效半径 √(面积/4π) ≈ 0.74 ≈ 7.5ℓ；网格边长中位数在球面 L6 上为 ℓ/5，在青蛙上为 ℓ/6.5。`summary.json` 的 `scales` 字段逐项列出。

**空间离散。** 默认用内蕴 Delaunay 的 robust Laplacian（Sharp & Crane 2020），所有边权非负，因此 (cM − αL) 是 M 矩阵，隐式扩散步保正、满足最大值原理。青蛙上经典 cotan 有 3.4% 的负权重，robust 为 0。质量矩阵用集中（重心）质量。ΔΓu ≈ M⁻¹Lu。

**时间推进。** IMEX：扩散隐式，反应显式。默认 SBDF2：前 2 万时间单位用 dt = 1 解析暂态，之后用 dt = 4 推进慢弛豫，直到 rms|∂u/∂t|、rms|∂v/∂t| < 1e-7，最长 t = 40 万。格式的不动点满足 DuLu + Mf(u,v) = 0，与 dt 无关，所以后期放大步长不影响稳态本身。显式稳定上限约 h_min²/(4Du) ≈ 1.3e-3，IMEX 在 dt = 8 时仍稳定。

**稳态精修。** 时间推进收敛后，用伪瞬态延拓（M/Δτ − J)δU = R(U)，Δτ 按残差下降自适应增大，最后退化为 Newton，把相对残差压到约 1e-12。这也是后续「AI 预测 → 求解器精修」的精修组件。

**初值协议。** 用题给建议初值 G = exp[−6(z − 0.05cos6θ)²]，其中 z 按曲面半高归一化（单位球上不起作用），叠加 (u, v) = (1/2, 1/4) 的局部种子和 5% 平滑噪声（相关长度 0.05），固定随机种子 0。理由见下方「初值敏感性」：斑点参数下 F < 4(F+k)²，不存在非平凡均匀平衡，光滑初值会整体塌缩到 (1, 0)。青蛙的 z 只有 ±0.48，不归一化时条带会覆盖全身。

**诊断定义。**
- PDE 残差：强形式 R = DΔu + f(u,v) 的面积加权 RMS，除以 F，称为 `steady_rel`。
- 线性稳定性：半离散 Jacobian 在 0 附近的 8 个特征值（shift-invert ARPACK），max Re λ < 0 即线性稳定。单位球上应出现 3 个约等于 0 的刚体旋转模态。
- 斑图统计：阈值取 v 的 5% 与 95% 分位数中点，统计高 v 相的连通分量数、面积分数、欧拉示性数、周长、紧致度 Q = 4πAn/P²（圆斑约 1，条纹远小于 1），以及 Dirichlet 比波长 λ = 2π/√(∫|∇v|²/∫(v − v̄)²)。

**可微性。** 线性求解是自定义 autograd 函数。A = cM − αL 对称，反向传播只需再解一次：∂ℒ/∂b = A⁻¹g，∂ℒ/∂α = (A⁻¹g)ᵀLx。因此能对 F、k、Du、Dv 和初值求梯度；长时程用梯度检查点（`rollout(..., checkpoint_every=k)`）。LU 后端（SciPy，float64，CPU）用于校核；CG 后端（纯 PyTorch，Jacobi 预条件）可上 GPU，支持每列不同参数的批量。

### 组委会答复「稳态解」后的复核（`scripts/steady_hypothesis.py`，`results/steady_hypothesis/`）

组委会联系人的初步答复：`Solution.mat` 是未归一化的原始浓度，并且是稳态解。回答者注明这不是其专业，更具体的问题会请教专业老师后再回复。

我们检验了「稳态 + 小幅噪声」这一假设。

**参数层面，与之前的结论一致：**
- 拉普拉斯项会放大噪声，导致原始数据上拟合出的扩散系数被压低（变量误差偏差）。
- 逐步平滑后做强形式拟合：Du 升到 2.8e-4，F ≈ 0.029，k ≈ 0.062，Dv/Du ≈ 0.30–0.37，拟合优度升到 0.91 / 0.97。
- 弱形式拟合（LB 特征函数为检验函数，数据不求导）：u 方程拟合优度 0.94–0.98，给出 Du ≈ 2.1–2.7e-4、F ≈ 0.030。
- v 方程里 Dv 无法单独辨识：斑图集中在主波数 κ₀ 附近，Dv·κ₀² 与 F + k 几乎共线，只能定出它们的组合；k ≈ 0.061–0.064。
- 两条独立途径都指向：题给斑点参数（F ≈ 0.028–0.034，k ≈ 0.061–0.062，Du ≈ 2.5–2.8e-4），唯一出入是 Dv ≈ Du/3 而不是 Du/2。

**但在精确求解器下，它不是稳态：**
- 从去噪并截断到 [0, 1] 的目标出发，换任何候选参数（包括题给原值），逐点相关都按反应时间尺度下降：t = 20 时 0.95，t = 50 时 0.82–0.85，t = 100 时 0.52–0.67。Newton / PTC 也找不到附近的稳态。
- 如果是「稳态 + 噪声」，噪声会很快被抹平，相关应该停在约 0.99。
- v < 0 的点是平滑的「负平台」，邻点均值同为 −0.025，不是孤立尖刺，所以不是显式格式的数值振荡。
- 这些点集中在青蛙下半身：z < −0.3 处占 29%，上半身只有 0.5–1.4%。最小值 −0.17 在腹部的大单元上。
- Gray–Scott 的反应项会把 v < 0 拉回 0，而一个近乎平坦的负平台几乎没有扩散作用来维持，所以它不可能是稳态。

### 按「原始浓度 + 稳态解」方向的系统研究（2026-10-18）

在专业老师答复前，我们把组委会的说法当作前提，系统检验了它的推论。相关脚本：
- `steady_forensics.py`：离散格式取证
- `stationarity_inversion.py`、`stationarity_constrained.py`：漂移最小化
- `steady_runs_report.py`、`results/steady_runs/run_all.sh`：稳态解与目标对比

**1. 稳态的两条必要条件**
- **最大值原理**：对任意正参数，Gray–Scott 在闭曲面上的稳态必满足 0 < u ≤ 1、v ≥ 0。论证：在 v 的最小值点 Δv ≥ 0，而稳态方程给出 Dv·Δv = v·((F + k) − uv)，若 v < 0 则右端 < 0，矛盾。单调离散（边权非负 + 集中质量）同样精确成立。
- 数据违反这一条：v < 0 覆盖 11.7% 的面积（最低 −0.17），u > 1 出现在 0.19% 的顶点。
- **积分恒等式**：对方程在全曲面积分，扩散项为零，得到 F = ∫uv² / ∫(1 − u) 与 F + k = ∫uv² / ∫v。这两式与拉普拉斯的离散方式无关，也不需要对数据求导。
- 由此得：F = 0.0288–0.0295，k = 0.061–0.065（截断不可能值后为 0.0290 / 0.0611），与题给斑点参数 0.028 / 0.062 相差约 4%。

**2. 离散格式取证**
- 候选离散共 26 种：P1 三角元（3 种四边形拆法 × 集中 / Voronoi / 一致质量 × 两种非线性项处理）、Q1 双线性四边形元、4 种图拉普拉斯。
- 在原始数据上，没有一种能让稳态方程成立：R²(u) ≤ 0.75，R²(v) ≤ 0.93，拟合参数几乎不随离散变化。
- 无法解释的部分是所有离散共有的小尺度成分。它在 u、v 间强相关（−0.94），外观呈块状。

**3. 异常的来源（尚未查明）**
- 已排除：各自独立的加性噪声（因为 u、v 强相关）、从笛卡尔网格插值（三轴周期图无一致峰）、相近曲面间的串扰（负值与「到对面曲面的距离」无关）。
- 负值区呈「负斑」形状，主要在后腿下侧和前腿。

**1. 预处理**（`turing_rd/preprocess.py`）
- 热核低通：做 n = 8 步隐式热方程，传递函数为 (1 + τκ²/n)^(−n)；τ 的取法使截断波数 κ½ 处的传递恰为 1/2。
    - robust Laplacian 的边权非负，所以 (M − τ/n · L) 是 M 矩阵。
    - 因此滤波保持均值、不产生新极值，不会把合法值推出 [0, 1]。
- 然后截断到 0 ≤ u ≤ 1、v ≥ 0。依据是最大值原理：稳态必在这个范围内。
- κ½ 由残差曲线决定，全程不用真值：
    - 对每个候选 κ½，先把目标滤波并截断，按积分恒等式求 F、k，再用题给 Du、Dv 算强形式稳态相对残差。
    - 滤波太弱时，噪声经拉普拉斯放大 κ² 倍；太强又会抹掉斑点。
    - 取残差进入平台（在最小值 2% 以内）的最弱滤波：κ½ = 20，等效高斯核宽 0.060，约 λ/8。

**3. 方向性与缺陷特征**
- 实现在 `turing_rd/features.py`。用 `FeatureExtractor(g, extended=True)` 时，在原 37 个特征之后再加 9 个；默认仍是 37 个，旧脚本和数据集不受影响。
- 方向性：
    - 每个三角形上 ∇v 的结构张量，用热核平滑到窗口 σ = 0.2，再投影到切平面。
    - 相干度：(μ1 − μ2)/(μ1 + μ2)，按梯度能量加权平均。
    - 轴向序：相干度 × cos 2φ 的加权平均，φ 是主梯度方向与体轴切向投影的夹角。
    - 体轴：面积二阶矩的主轴，青蛙上是头尾方向；接近各向同性的曲面（球面）取 z 轴。

**4. 反演流程**
1. 类型图：在经典范围（Pearson 1993）F 0.01–0.07、k 0.04–0.07 上取 13 × 13 个点，各用 1 个初值积分到 t = 5000。斑点只出现在鞍结线 F = 4(F + k)² 上方的一条窄带里，真值和闭式初值都在带内（`landscape.png` 左图）。
2. 网格：以闭式初值为中心，ΔF = 0.002、Δk = 0.001，共 7 × 7 个点。
    - 每个点用同样 6 个固定随机初值（种子 1000–6000），即共同随机数；初值同基线协议。
    - SBDF2：t ≤ 500 用 dt = 1，之后用 dt = 8。6 个初值作一批，共享 LU。
    - rms|dv/dt| < 1e-6 时交给 PTC 精修；残差 < 1e-10 即退出。
    - t = 2 万后仍 > 3e-4 的，判为持续动态，提前退出。
    - 上限 t = 4 万；到时 < 1e-5 的再精修一次。
3. 特征距离 J_feat：
    - 每项评分判据内，对特征误差（按容差归一）取 RMS；再对三项判据取 RMS，三项等权。
    - 容差与同一参数下种子间的散布同量级：波长和谱质心 ±5%（散布 1.2%）；相干度 ±0.05（0.02）；轴向序 ±0.1（0.03）；缺陷斑比例 ±0.15、端点密度 ±0.2、分叉密度 ±0.1、骨架密度 ±0.2（散布 0.06 / 0.12 / 0.04 / 0.06）。
    - 只认稳态：要么精修到 1e-10，要么 t = 4 万时 rms|dv/dt| < 1e-5。后者相当于 dt = 1 时每步变化 1e-5，比老师的「相邻两步变化 < 1e-4」更严。
    - 类型不对或未达稳态的种子罚 5。J_feat 取稳态斑点种子的中位数；稳态斑点种子不足一半的点视为不可行。
4. PDE 残差判据 J_pde：
    - 即目标在 (F, k) 处对常数检验函数的弱形式残差，也就是两条积分恒等式的相对偏差。
    - 除以截断取 0.8–1.25 倍造成的不确定度：F 为 2.3%，F + k 为 1.9%。
    - 与三项特征判据等权合并：J_total² = (3 J_feat² + J_pde²) / 4。
5. GP 代理（AI 部分）：
    - 在可行点上对 J_feat 做高斯过程回归：RBF 核，每点噪声取种子自助标准误。
    - 可行域由另一个 GP 回归「稳态斑点种子比例」，取 ≥ 0.5 的部分。
    - 在 121 × 121 的细网格上求极小。不确定带取 J ≤ 极小 + 2 个标准误；另做 200 次种子自助。
6. 终态：在最终参数、仅特征最优点和题给参数下各跑 6 个初值，积分到 t ≤ 8 万；PTC 精修到 1e-12 以下，并求 Jacobian 在 0 附近的 8 个特征值。

**网格的主要发现**（`landscape.png`、`criteria.png`）
- 第一版（`results/inversion_v1/`）没有稳态约束，仅特征的最优点落在 F = 0.023、k = 0.058。
    - 复算发现，那里 6 个初值到 t = 8 万都没有达到稳态：残差 2e-3 到 3e-2，斑点不断自复制。
    - 那一版比的其实是暂态快照，所以加了稳态约束。
- 稳态斑点只存在于 F ≳ 0.027、且在条纹边界之上的区域（k ≳ 0.0586–0.0606，随 F 增大），真值在其中。F ≤ 0.0255 的整片区域几乎没有稳态斑点（持续自复制或消亡）；越过条纹边界则变成条纹或迷宫。294 次求解里有 44% 精修到 1e-10，60% 达到稳态判据。
- 区域内 J_feat 只在 1.80–2.28 之间，单点标准误约 0.07。
    - GP 在 F 方向的相关长度达到上限（30 个格点），即沿 F 是平的；只对 k 有弱偏好，偏向更低的 k（缺陷更多）。
    - 所有可行点的波长都在 0.482–0.498，目标是 0.547，大 10–13%。
    - 缺陷斑比例在靠近条纹边界处能升到目标的水平，但这时相干度也升到 0.44（目标 0.31）。
    - 所以单靠形态特征定不了参数：目标比任何稳态都尺度大、缺陷多，这与参数无关。
- 仅特征的最优点 (0.0301, 0.0598) 在可行域边缘。终态复算时，6 个初值里 2 个变成条纹，2 个未达到稳态。
- 积分恒等式带来了特征所没有的幅值信息，把 F、k 钉住；合并后 F 误差 −1.0%，k 误差 −3.2%。

**不确定度**
- 最终估计的带：F 0.0267–0.0287，含真值 0.028；k 0.0598–0.0613，真值 0.062 在带外 0.0007。
- 截断敏感性：κ½ 取 16 / 25 时，最终估计为 (0.0272, 0.0603) / (0.0282, 0.0599)。
- 种子自助只改变特征项，极小点几乎不动（F 0.0277–0.0278，k 0.0600）。可见位置主要由 PDE 判据决定，带宽主要来自截断的不确定度。
- k 的系统偏低来自截断：不截断时闭式 k 为 0.0608。

**结论**
- 按评分口径：
    - 类型正确，是斑点。
    - 终态残差在 1e-14 量级，Jacobian 在 0 附近的特征值全为负。
    - F、k 误差为 −1.0% / −3.2%，在老师说的「不要求参数绝对误差极小」范围内。
- 波长、方向性、缺陷这些特征在稳态斑点区内对参数不敏感，而目标比任何稳态都缺陷多、尺度大。报告里应如实写明：
    - 特征匹配的作用是圈定可行区并校验类型。
    - 参数精度来自 PDE 积分恒等式。
    - 特征对照表应和题给参数下的稳态一起给出：题给参数本身也只能做到同样的距离（J_feat 2.15，最终估计为 2.01）。

### AI-PDE 生成（任务 1、2，2026-10-20，`scripts/ai_generation.py`，`results/ai_generation/`）

规则要求每个任务都含 AI 方法，纯求解器方案不予采用；之前的生成只有求解器，这里补上 AI 部分。只用 CPU。

**方案：AI 给初值，Newton 精修**
- 训练数据：在题给网格上自己生成。参数网格为 F ∈ [0.020, 0.060]（9 档）× k ∈ [0.057, 0.065]（5 档），Du、Dv 用题给值。每个曲面 45 个点，用普通流程跑到稳态，记录类型和统计量。
    - 青蛙：条纹 14、斑点 11、均匀 11、孔洞 9。
    - 单位球 L5：斑点 13、条纹 10、均匀 14、孔洞 8。
- AI：几组小型 MLP（scikit-learn，CPU，拟合 5–8 s）。
    - 输入 (F, k)，预测斑图类型。
    - 对斑点：预测斑点密度和径向剖面 u(r)、v(r)。
    - 对其它斑图：预测 LB 谱环 (κ₀, γ)、v 的分位数和 u–v 关系（`turing_rd/ai_init.py`）。
- 初值：
    - 斑点：按密度 × 面积定斑点数，用 Lloyd（质心 Voronoi）迭代均匀布点，每点放预测剖面。
    - 条纹：取波数 κ₀/2 的随机场的节线邻域，得到连通迷宫。

- 两个题给参数点和 6 个随机点都不在训练网格上，都是泛化测试。
- 一条命令复现：`python scripts/ai_generation.py all`（任务完成即存盘，可续跑）。

**关键发现**
- 旧的 PTC 精修是瓶颈：伪时间步从 50 起步，40 次迭代只能把残差压低 2–10 倍。
- 改用带线搜索的 Newton 后：从相对残差 1e-5 出发约 9 次迭代（2 s）到 1e-14。Jacobian 经有限差分验证（误差 3e-8）。

## 已知事项与下一步

- GPU 求解器要换。实测（见上一节）现有 GPU CG 并不比 Mac 的批量 LU 快。
    - 建议改用完整 LB 特征基的稠密变换：x = Φ diag(1/(c + αλ)) Φᵀ b。
    - 这样每次求解只是两次稠密矩阵乘，天然支持每列不同的 Du / Dv，反向传播也是同一变换。
    - 青蛙网格的 Φ 为 29k × 29k，float32 约 3.4 GB，放得进 12 GB 显存。
    - 特征分解只需做一次：在笔记本 CPU 上 float64 约需 20 GB 内存。
    - 另一个用途是把 GPU 留给神经网络训练。
- 球面迷宫纹的残余漂移：可加一个「去掉刚体旋转」的 Newton（对 3 个旋转方向加约束），把残差压到 1e-12。
