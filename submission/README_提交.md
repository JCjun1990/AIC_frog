## 4. 环境与复现

在 ZIP 解压根目录执行以下命令。Python 3.11/3.12，CPU 即可。
下面的 `python` 必须指向已安装依赖的解释器；安装命令仅供复现者自行选择，本次修复未安装依赖。

```bash
python -m venv .venv
# Linux/macOS:
.venv/bin/python -m pip install -r code/requirements.txt
# Windows PowerShell:
.venv\Scripts\python.exe -m pip install -r code/requirements.txt
```

使用环境内解释器后，以下命令在 Windows/Linux 共用：

```bash
python code/scripts/submission_workflow.py verify --submission .
python code/scripts/submission_workflow.py prepare-models --submission . --out reproduction_inputs
python code/scripts/ai_generation.py generate --out reproduction_inputs --generate-out reproduction_runs/tasks --generate-surfaces frog sphere6
```

`prepare-models` 将网络复制为 `reproduction_inputs/frog/model.joblib` 与
`reproduction_inputs/sphere5/model.joblib`，不依赖旧 `results/` 或 shell 复制命令。
输出目录存在时拒绝覆盖。
`generate` 的 4 个任务并行运行（`--workers`，默认最多 4 个进程），种子按任务固定：球面条纹用种子 2，其余用种子 0
（`TASK_SEEDS`；种子 0 的球面条纹会落到带 +1.67e-6 可靠正倾斜模态的六条带态，故不用；可用 `--generate-seed sphere6:stripes=0` 复查）。
交接方报告：2026-10-26 在 Windows CPU（全新解压的包，Python 3.13）上按本命令运行，总耗时 47.5 分钟（含首次计算网格特征基约 10 分钟）；
青蛙斑点 22 斑、球面斑点 45 斑、球面条纹七条带（最大实部 −1.4778e-6）与正式结果为同一稳态；青蛙条纹为 5 段迷宫，
类型一致且稳定，但多稳的迷宫对浮点运算顺序敏感，不同运行可能落在同类的另一个稳态。四组均满足完整残差 ≤ 1e-11 且已采样谱为负。
正式提交的是包内经证书绑定的四组 MAT；精确回读验收用第一条命令。
上述生成耗时和形态复现来自交接说明，未随此分支提供原始运行日志；本轮重新打包不重跑该生成实验，也不把该耗时作为新 ZIP 的测量值。

`verify` 的每项输出带 `verification_mode`：优先严格验收；仅算子指纹不同或残差对账超出严格比较预算时，尝试 `portable`。
即使 L/M 指纹一致，残差归约的浮点舍入差异也可进入 portable；模式不按 x86/ARM 名称选择。
portable 保留完整的证书结构、参数、种子、公式、容差与 MAT 哈希检查。网格哈希、点面数和 robust 算子类型须一致，总质量在相对 1e-12 内一致；保存值与本机完整残差均须满足原有 ≤ 1e-11 标准，且二者在固定 1e-12 绝对比较预算内一致。
这是跨平台数值验收，不是完整 L/M 矩阵逐元素等价证明。

四组正式谱证书只有保存的逐特征对元数据，验收按固定政策核验，未重新求谱或回算未保存的向量。
最佳匹配另外保存三组共 40 个特征向量，其残差在本机重算，对账误差在固定谱残差通过阈值的千分之一内，
最终有限谱判定使用本机重算的特征对残差；任一本机检查失败均拒绝通过。
交接方还报告同日在 Apple M 系列 Mac 上五项 portable PASS（最佳匹配残差 2.03e-14 → 2.85e-14）；
本轮仅能独立验证当前 Windows 环境及模拟的算子舍入差异，新 ZIP 仍须在 Windows 笔记本和真实 ARM Mac 上分别回验。
