# 主动学习（不确定性采样）与端到端效率

v2 在 4096 个候选点上按类型不确定性挑出每曲面 48 个点（2 个初值），补跑 PDE 稳态后重训为 v3。选点不使用测试集。

| 曲面 | 测试集类型准确率 v2 → v3 | 加密网格留一验证：不加 / 全加 / 只加两初值一致的 | 新点中两初值类型不同 |
| --- | --- | --- | --- |
| frog | 92.2% → 82.8% | 86.3% / 86.3% / 86.9% | 11/48 |
| sphere5 | 95.3% → 92.2% | 92.8% / 93.8% / 93.5% | 17/48 |

结论：边界附近的不确定性主要来自多稳态（同一参数、不同初值得到不同类型），补样不能消除，验证集无明显提升、测试集反而下降，因此不采用 v3，最终网络为 v2。
